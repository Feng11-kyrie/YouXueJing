# 优学鲸 · 408 考研知识图谱

面向 408 考研（计算机学科专业基础综合）的**知识点图谱与真题标注数据集**。

本仓库是整个「优学鲸」项目的**数据层**：把官方考试大纲结构化成知识点图谱，
再用 18 年（2009–2026）共 846 道真题完成考点标注，并构建知识点前置依赖图。

> ⚠️ **本仓库不包含试题原文。** 详见下方[版权与数据边界](#版权与数据边界)。

---

## 这份数据集有什么

| 资产 | 规模 | 说明 |
|---|---|---|
| **考纲知识点树** | 4 学科 / 24 章 / 116 节 / 214 考点 | 依据官方考试大纲逐条结构化 |
| **叶子候选集** | 266 个 | 打标用的最小粒度单元（树深度变长，故按叶子而非固定层） |
| **真题考点标注** | **846 题**（720 单选 + 126 综合） | 每题 1 个主考点 + 0–2 个次考点 + 难度 + 置信度 |
| **考点频次统计** | 266 个考点 × 18 年 | 234 个考点被考到（88%），32 个从未考过 |
| **知识点依赖图** | **339 条前置边**（无环 DAG） | 支撑「薄弱点 → 追溯根因 → 补前置」 |

## 为什么做这个

个性化学习推荐的关键不是「给你一堆题」，而是**找到知识断点**。

举例：用户画像显示「红黑树」掌握度 35%。没有依赖图时系统只能推红黑树的题——用户依然做不出。
有了依赖图，系统会向上追溯前置链：

```
红黑树              35%
  ↑ 前置
平衡二叉树           42%   ★ 断裂点
  ↑ 前置
二叉搜索树           38%   ★ 断裂点
  ↑ 前置
二叉树的定义及主要特性  88%   ✓ 已掌握
```

→ 正确动作是**先补「二叉搜索树」**，而不是练红黑树。

这就是本仓库「依赖图」存在的原因。

## 数据格式

### 知识点树节点

```json
{
  "id": "DS-06-05-02",
  "level": 4,
  "parent": "DS-06-05",
  "name_official": "平衡二叉树",
  "name_plain": "平衡二叉树",
  "aliases": [],
  "exam_freq": null,
  "depends_on": []
}
```

**编码规则**：`<学科>-<章>-<节>-<考点>`，学科码 `DS` 数据结构 / `CO` 计算机组成原理 / `OS` 操作系统 / `CN` 计算机网络。

> 用**语义化编码**而非名称作为 key —— 大纲条目名会修订，四门课之间也存在同名概念（如「地址」「调度」）。

### 题目标注（已剥离试题原文）

```json
{
  "id": "408-2024-38",
  "year": 2024,
  "题号": 38,
  "题型": "单项选择题",
  "学科": "计算机网络",
  "分值": 2,
  "需插图": false,
  "主考点": "CN-05-03-03",
  "主考点名": "TCP 可靠传输",
  "次考点": ["CN-05-03-01"],
  "次考点名": ["TCP 段"],
  "难度": 3,
  "置信度": 0.9
}
```

### 依赖边

```json
{

  "置信度": 0.85
}
```

## 方法论

### 1. 打标粒度：叶子级

树的**深度是变长的**——大纲对四门课的细化程度不同：

| 学科 | 叶子所在层级 | 叶子数 |
|---|---|---|
| 数据结构 | 多在 L3（节） | 56 |
| 计算机组成原理 | 多在 L4（考点） | 64 |
| 操作系统 | 多在 L4（考点） | 61 |
| 计算机网络 | 多在 L4（考点） | 80 |

因此统一标到**叶子节点**（不管它在第几层），展示时再向上聚合到章/节。

### 2. 打标用封闭候选集

先由题号区间确定学科，再在**该学科的 56–80 个叶子**中选择（而非全量 266 选 1）。
候选集封闭意味着模型不会发明大纲外的知识点——**846 条标注中自造 id 数为 0**。

### 3. 双重校验修正学科归属

最初假设「学科由题号区间唯一确定」，但**该假设对 4 个年份不成立**。用两道独立证据裁决：

- **官方分值硬约束**：单选固定 80 分 → 综合题必为 数据结构 2题23分 / 组成原理 2题23分 / 操作系统 2题15分 / 计算机网络 1题9分（纯算术，可穷举验证）
- **题干内容判定**：逐题读题干判断学科

两者结论完全一致，共修正 10 道题（2009 / 2014 / 2016 / 2019）。

### 4. 依赖边两个来源

| 来源 | 边数 | 依据 |
|---|---|---|
| 同节链式 | 150 | 大纲在同一节内按学习顺序列出子考点，相邻两者构成前置链 |
| 跨节共现 | 234 | 从 846 题「主考点+次考点」共现挖掘，且前置在考纲顺序上更早 |

方向以**考纲全序**为先验（前置必然更早），因此在数学上不会成环。

## 数据质量清洗

PDF 的文字层会带进大量版式噪声。清洗前实测 **213/846 题（25.2%）被污染**，共修复 **313 处**：

| 问题 | 处数 | 示例 | 处理 |
|---|---|---|---|
| **页眉页脚混入**（最严重） | 183 | 选项末尾被塞进「2009 年全国硕士研究生入学统一考试…第2页，共10页」 | 按模式删除整行 |
| **上标被拆成独立行** | 78 | `2⏎7⏎×⏎29/32` 实为 `2^7 × 29/32` | 还原为 `^` 记法 |
| 运算符独占一行 | 33 | `2⏎32⏎ – 2⏎15⏎ + 1` | 换行化为空格 |
| 章节标题混入 | 18 | 「二、综合应用题（第41～47 题，共70 分）」 | 按模式删除 |

**其中页眉页脚污染最值得注意**：它会出现在**选项文本里**，用户会直接看到一整行试卷页眉。

上标统一写成 ASCII 的 `^` 记法（如 `2^7`）而非 Unicode 上标（`2⁷`）——后者会破坏下游检索与匹配，渲染成真正的上标是前端的职责。

清洗后复查：5 类污染**残留均为 0**，846 题结构与 720 个答案完好无损。

## 插图抽取

118 道题的题干里有「如图」「如题 7 图所示」这类引用，但图是 PDF 里的位图，不在文字层里。
`extract_figures.py` 把插图抽出来并映射回题目，成功 **102 题**。

映射依据分四级（`_图片依据` 字段可审计）：

| 依据 | 题数 | 含义 |
|---|---|---|
| 题注 | 30 | 图下方/上方有「题 N 图」字样，直接给出题号 |
| 题干引用 | 57 | 该题题干含插图引用（`FIG_RE`），取图片上方最近的一道 |
| 需插图标记 | 4 | 由上述规则间接定位 |
| 就近回落 | 11 | 无题注也无引用，按版面就近归属（置信最低） |

抽取过程中处理了四个坑：

1. **页面级变换** —— 内容流开头的 `0.75 0 0 -0.75 0 841.92 cm` 必须先套用，
   否则所有坐标都是错的。但部分年份（如 2024）**没有**这个变换，其内容流的
   第一个 `cm` 其实是某张图的放置矩阵，误当成页面变换会让坐标全部跑飞。
2. **`page.images` 的顺序不是视觉顺序** —— 必须从内容流解析 `cm` + `Do` 拿真实坐标，
   再配合题注位置配对。
3. **图可能包在 Form XObject 里** —— 2024 年的插图是 `/Meta38 -> /Image39` 这样的嵌套结构，
   需要递归进 Form 并复合其 `/Matrix` 与 `/Resources`；同时不能把所有 `/Name Do`
   都当图片（Form 也可能是矢量绘制）。
4. **一条图被切成多张横条** —— 2018 年第 44 题的图被切成 11 条，需按坐标识别相邻块并纵向拼接。

另外还需处理两类编码：JPEG 交给 PIL 直接读；**`/FlateDecode` 原始像素**（2023/2024 部分插图）
PIL 认不出，要按 `/ColorSpace` 与 `/Width /Height /BitsPerComponent` 自行重建。

## 已知局限

- **27 道题正文引用了插图但没有抽到图**（`_缺图: true`）。其中大多数是「如下所示」实为
  **内联表格或代码**（伪代码、段表、指令格式），本就不需要位图；少数是真实缺口，需人工补。
- **11 道题按版面就近归属插图**（`_图片依据: 就近回落`），置信最低，建议人工复核。
- **依赖边中 127 条仅单次共现**（置信度 0.5），证据较弱，需人工复核。每条边的「依据」字段可直接判断是否成立。
- **跨学科依赖尚未构建**（如组成原理的「存储层次」↔ 操作系统的「内存管理」）。
- **综合应用题无客观答案**（主观题），自动判分只覆盖 720 道单选。
- **考点掌握度数据不在此仓库**（属于运行时用户数据）。
- 大纲各考点的「掌握 / 理解 / 了解」要求等级未包含——公开转载版大纲不含该信息。

## 版权与数据边界

本仓库**只公开知识图谱结构与代码**，具体边界如下：

**包含**（自有劳动成果）
- 考试大纲的层级结构编码、语义化 ID 体系、通俗名称
- 846 道真题的**考点标注、难度、频次、依赖关系**（结构化衍生数据）
- 全部构建脚本

**不包含**（他人版权内容）
- 试题题干、选项、答案原文
- 试卷与答案解析的 PDF 原件
- 答案表扫描图

试题原文相关材料保留在本地，不进入版本控制（见 `.gitignore`）。

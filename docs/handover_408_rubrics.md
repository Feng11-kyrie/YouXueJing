## 一、目标

把 408 综合题、政治分析题的免费评分，从"字数+分点+考点词"升级为
**按官方评分标准的分档给分**（学生答到什么程度 → 落到哪一档）。

## 二、已验证的关键事实

### 408：权威源存在且**可机读**

样例：<https://static.kaoyan.cn/file/question/2025/11/04/ea4c362c1e27e35785676e188b094e37.pdf>
（考研网 kaoyan.cn，841KB，**文字型 PDF，570 行，非扫描件**）

提取方式已验证可用：

```python
from scripts.parse_english import norm_lines   # 本项目已有的 PDF 取行工具
lines = norm_lines('/tmp/k2025.pdf')
```

PDF 里的评分标准形态（实测 2025 年第 41 题）：

```
（1）给出算法的基本思想。(4 分)
（2）用 C/C++ 描述算法关键之处给出注释。(7 分)
（3）说明时间、空间复杂度。(2 分)
【评分标准】
（1）算法基本思想（4 分）
①若考生清晰、准确地描述了能达到时间复杂度为 O(n)的算法基本思想，可得 4 分。
②若描述的算法思想存在一些不清晰的地方，但能大致体现出正确的方向，可酌情给 2 - 3 分。
③若算法思想完全错误，得 0 分。
（2）C/C++ 算法实现及注释（7 分）
①若考生所给算法实现正确，且时间复杂度为 O(n)，可给 7 分。
②……时间复杂度超过 O(n)……最高可给 5 分。
③若算法实现部分正确……参照上述……
```

**要点：这是"分档给分"（含"酌情 2-3 分""最高 5 分"），
比单纯的采分点更接近真实阅卷逻辑。**

### 政治：不存在逐题阅卷细则

- 阅卷细则由各省考试院组织，属内部材料，不公开
- 权威近似物：**《考试分析》**（教育部考试中心编，高教社）—— 含真题官方参考答案、
  命题思路、考生答题情况分析
- 用户明确要求：**这条限制不要写进界面**

### 1. `scripts/fetch_408_rubrics.py`

- 逐年找到 kaoyan.cn 的 408 答案 PDF URL（2010–2026，2026 年的要等新链接）
- 下载 → `norm_lines()` → 定位 `【评分标准】` 到下一个题号之间
- 解析成结构化 JSON：

```json
{"41": {"满分": 13,
        "档次": [
          {"步骤": "算法基本思想", "分值": 4,
           "档": [{"条件": "清晰准确描述 O(n) 算法", "得分": "4"},
                  {"条件": "不太清晰但方向正确", "得分": "2-3"},
```

- **必须做的校验**：各步骤分值之和 == 该题满分；不对就跳过并记录

- 输出：每步的档与得分 + 未达成的步骤（"你漏了'复杂度分析'，2 分"）
- **没有 rubric 时自动退回现在的 `score_generic()`**（三段式）

### 3. 界面

   且作者专栏里看不出覆盖多少年 —— **优先用 kaoyan.cn 的 PDF**

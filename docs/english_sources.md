# 考研英语真题：数据源与结构（实测记录）

> 本文件记录**实测结论**，供后续导入与维护参考。不是设计文档，是"查证过的事实"。

## 一、题源（两个互补的来源）

### 1. 试题（干净、无答案）—— GitHub 开源仓库
`https://github.com/Fantasia1999/kaoyanzhenti`

    公共课/英语真题/英语一/  1998–2026（含合集 PDF）
    公共课/英语真题/英语二/  2010–2026

* **文字层干净**（每份 14 页、2.5–3.4 万字）—— **不需要 OCR**
* **但没有答案**（实测三个合集 PDF 的"答案/解析/参考答案"计数都是 0）
* README 声明：2023–2026 的 PDF 来自 `zhenti.burningvocabulary.com`，仅去水印

### 2. 答案与解析 —— 懒笔记
`https://english-exam.lazynote.cn/kaoyan/`

* **分节页**（本项目主要用它）：`/kaoyan/sections/<年>-english-<one|two>/<节>/`
    节名：`section1` · `section2-part-a-{1,2,3,4}` · `section2-part-b` ·
          `section2-part-c` · `section3`
* **整卷 PDF（含答案解析）**：
    `https://downloads.lazynote.cn/kaoyan/<年>-english-<one|two>/`
    文件名形如 `考研英语一<年>真题及答案解析（整卷）.pdf`
    实测 2024 英语一那份：**147 页 / 19 万字**，含逐空解析
* 分节页内容质量高：每题有 **答案 / 题型判定 / 题干拆句 / 定位句中英对照 /
  逐选项对错归因**，还给出答案分布（如"答案分布 A 2 题 / B 1 题 / D 2 题"）

### 实测的抓取注意点

* **要先用浏览器访问一次 `/kaoyan/` 建会话，且请求之间停顿约 1 秒**。
  否则会出现"整年 0/8 可用"的假失败（我第一次探测 2020/2026 就是这样误判的，
  加会话和延后复测变为 7/8 和 6/8）。
* 每卷稳定可拿到 **6–7/8 节**；缺的通常是 `section3`（写作）——
  写作是开放式作文，本来就没有"答案"。

## 二、卷子结构（英语一/英语二 **题号体系相同**）

| 部分 | 题号 | 题型 | 英语一 | 英语二 |
|---|---|---|---|---|
| Section I 完形 Use of English | 1–20 | 四选一（一篇文章 20 空） | 20×0.5=10 | 同左 |
| Section II Part A 阅读 | 21–40 | 四选一（**4 篇 × 5 题**） | 20×2=40 | 同左 |
| Section II Part B 新题型 | 41–45 | 选句/排序/小标题（**A–G 选 5**） | 5×2=10 | 同左 |
| Section II Part C 翻译 | 英语一 46–50 / 英语二 46 | 主观（英译汉） | 5句×2=10 | 1段=15 |
| Section III 写作 | 51（小）/ 52（大） | 主观 | 10+20=30 | 10+15=25 |

**注意**：英语一与英语二**题号完全一致**（1–52），差别只在 Part C 与写作的分值。

## 三、文字层解析要点（踩过的坑）

* **英文单词间是双空格**（PDF 两端对齐造成）：`'Nearly  2,000  years  ago'`
  → 必须 `re.sub(r'[ \t]{2,}', ' ', ...)` 归一化
* **页码混在正文里**：`'... to a  curious treasure'` 里的 `a` 后面其实是页码 `2`
  → 单独成行的纯数字要先剔除
* **跨页会丢词**：`'they '` 与 `'curious'` 之间原文是 `left behind a`，
  但 `left behind a` 出现在**上一页末尾**，逐页拼接时会丢
  → 解析正文时要留意，必要时用懒笔记的整卷 PDF 交叉校对
* **选项形式**：`21. 题干` 换行后 `A. xxx` / `B. xxx`（干净，`A. ` 行首）
* **新题型用括号题号**：`(41) Hannah`，与 1–20 的 `1` 形式不同，要单独处理
* 懒笔记整卷 PDF 的**填空处选项字母会丢**（`'  the need to be'` 前应有 `[A]`），
  所以整卷 PDF 适合取"答案解析"，取题目请以 GitHub 那份为准

## 四、与政治/408 的结构差异（决定建模）

| | 政治 / 408 | 英语 |
|---|---|---|
| 卷种 | 一科一卷 | **一科多卷种**（英语一/英语二） |
| 题目形态 | 一题一卡（独立） | **复合**：完形 20 空共享 1 篇文章；阅读 4 篇×5 题 |
| 判分 | 选项字母比对 | 同左（客观题）；填空/翻译/写作不可自动判分 |
| 主观题 | 分析题（政治）、综合题（408） | 翻译、写作（**写作无标准答案**） |

→ 需要在现有的"一题一卡"之外，新增「**材料 + 多个小题**」这一层。
